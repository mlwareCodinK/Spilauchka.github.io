# Скачивалка видео с DPlayer

Вставляешь ссылку на страницу с плеером DPlayer — получаешь видеофайл.

Как работает: страница открывается в **чистом браузере без куки**, запускается воспроизведение, скрипт **ждёт ~60 сек** (буферизация), перехватывает ссылку на видео (mp4 или HLS/m3u8) и скачивает её. Профиль браузера после этого уничтожается.

## Termux (Android)

Одной командой (ставит всё нужное, скачивает проект и запускает):

    pkg update -y && pkg install -y nodejs git && git clone -b ccr-1b774c8b-uj3cfj https://github.com/mlwareCodinK/Spilauchka.github.io.git dpl && cd dpl && node server.js

ffmpeg ставить не обязательно: без него HLS (m3u8) скачивается сегментами в файл `.ts` (играет в VLC/MX Player). Если хочешь `.mp4` — `pkg install ffmpeg` (если падает с ошибкой dynamic library linking — смени зеркало командой `termux-change-repo`, затем `pkg upgrade -y`).

Потом открой в браузере телефона http://localhost:3000. Или без веб-формы: `node grabber.js "ссылка"`.
Повторный запуск: `cd ~/dpl && node server.js`.
В Termux браузер Chromium недоступен, поэтому работает режим без браузера: ссылка на видео ищется в коде страницы и её iframe (с пустыми куки), с повторами до минуты.

## Установка на компьютере (один раз)

Нужны Node.js 18+ и [ffmpeg](https://ffmpeg.org/) (для HLS/m3u8).

    npm install
    npx playwright install chromium

## Запуск с веб-формой

    npm start

Открой http://localhost:3000, вставь ссылку, нажми «Скачать». Файл попадёт в папку `downloads/` и предложится к сохранению.

## Из командной строки

    node grabber.js "https://сайт/страница-с-видео" 60

Второй аргумент — сколько секунд ждать буферизацию (по умолчанию 60).

## Ограничения

- Это работает только локально: GitHub Pages — статический хостинг, он не может ни открыть чужой сайт, ни чистить куки.
- DASH (.mpd) и видео с DRM не поддерживаются.

## Слайдер-проверка («拖拽滑块验证») и ручное управление

В режиме с браузером ползунок ищется и протягивается автоматически. Если не вышло (в логе будет «Слайдер автоматически не найден»), в веб-форме появляется живой скриншот страницы: зажми палец на ползунке, протяни до конца дорожки и отпусти. Для обычных кнопок выбери режим «Клик». Если мышь не срабатывает, включи «Касанием». После каждого действия ожидание буферизации начинается заново, а команда пишется в лог. В Termux-режиме без браузера этого нет.

## Запись кусков, пока видео играет

Если плейлист (m3u8) найти не удаётся, программа ловит каждый кусок видео (MPEG-TS), который сама подгружает страница, сохраняет его на диск, ускоряет воспроизведение до конца и склеивает всё в один файл (`.mp4`, если есть ffmpeg, иначе `.ts`). Лишние заголовки в начале кусков («под картинку») срезаются. Галочка в форме «Записывать куски…» включает этот режим всегда. Поддерживаются куски MPEG-TS (`.ts`) и m2ts (пакеты по 192 байта, `.m2ts`). Не поддерживаются куски в формате fMP4 (`.m4s`) и зашифрованные потоки: зашифрованные куски не расшифровываются.
Остановка: видео доиграло или 30 сек нет новых кусков (общий потолок — 60 мин, `MAX_RECORD_MIN`).

## Открывать как телефон

Переключатель «Открывать как это устройство» в форме передаёт на сервер User-Agent и размер экрана того устройства, с которого ты открыл форму. Браузер на VPS открывает сайт в мобильном режиме. Меняется только представление браузера, IP-адрес сервера остаётся прежним.
